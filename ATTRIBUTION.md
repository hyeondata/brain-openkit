# Attribution and licensing

Brain OpenKit is an independent project. The current repository contains original
design and community documentation. It does not bundle third-party application
code, model weights, or copied README artwork.

## Design reference

[`AgriciDaniel/claude-obsidian`](https://github.com/AgriciDaniel/claude-obsidian)
informed the idea of keeping Markdown knowledge connected to its original
sources. Its README also served as a reference for presenting a project's
workflow, scope, contribution path, and license clearly.

Brain OpenKit's current documents were written independently. This repository is
not a fork of claude-obsidian. If a future contribution copies code or templates
from that project, retain the applicable copyright and license notices from
the exact version used. See its [license](https://github.com/AgriciDaniel/claude-obsidian/blob/main/LICENSE)
and [attribution](https://github.com/AgriciDaniel/claude-obsidian/blob/main/ATTRIBUTION.md).

## Planned model integration

- [Laya code](https://github.com/NandhaKishorM/laya), published under
  [Apache 2.0](https://github.com/NandhaKishorM/laya/blob/main/LICENSE).
- [Laya multilingual weights](https://huggingface.co/convaiinnovations/laya-multilingual),
  identified as Apache 2.0 in the publisher's model metadata.
- [TypeSafe Jev](https://docs.typesafe.ai/introduction/quickstart), a planned
  optional hosted provider. Access to its API is governed by TypeSafe's service
  terms, separately from Brain OpenKit's license.

The project's MIT license does not relicense these components. Any future
distribution that includes third-party material must preserve its applicable
notices. Model metadata is not an audit of the underlying training data.
